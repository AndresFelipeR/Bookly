# 📚 Bookly

## Español

Sistema de gestión de reservas desarrollado con **.NET 9** siguiendo los principios de **Clean Architecture**, **Domain-Driven Design (DDD)** y **CQRS**.

Este proyecto se centra en aplicar prácticas modernas de desarrollo backend utilizadas en aplicaciones empresariales.

> 🚧 Actualmente en desarrollo activo.
